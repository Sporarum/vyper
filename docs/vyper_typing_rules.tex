\begin{abstract}
This document presents the formal typing rules for the Vyper smart contract programming language,
extracted from the compiler implementation. Vyper is a statically typed, Pythonic language
targeting the Ethereum Virtual Machine (EVM). These rules follow standard notation from
Pierce's \emph{Types and Programming Languages}~\cite{pierce2002types} and bidirectional
typing literature~\cite{dunfield2013complete}.
\end{abstract}

\section{Type Syntax}
%==============================================================================

\subsection{Base Types}

\begin{align*}
\tau ::= \quad & \kw{bool} && \text{Boolean} \\
\mid \quad & \kw{int}N && \text{Signed integer } (N \in \{8,16,\ldots,256\}) \\
\mid \quad & \kw{uint}N && \text{Unsigned integer } (N \in \{8,16,\ldots,256\}) \\
\mid \quad & \kw{decimal} && \text{Fixed-point decimal (168 bits, 10 decimals)} \\
\mid \quad & \kw{address} && \text{Ethereum address (160 bits)} \\
\mid \quad & \kw{bytes}M && \text{Fixed-size byte array } (M \in \{1,\ldots,32\}) \\
\mid \quad & \kw{Bytes}[n] && \text{Dynamic byte array (max length } n \text{)} \\
\mid \quad & \kw{String}[n] && \text{Dynamic string (max length } n \text{)} \\
\mid \quad & \kw{None} && \text{No value (statements, void functions)}
\end{align*}

\subsection{Composite Types}

\begin{align*}
\tau ::= \quad & \tau[n] && \text{Static array of length } n \\
\mid \quad & \kw{DynArray}[\tau, n] && \text{Dynamic array (max length } n \text{)} \\
\mid \quad & \kw{HashMap}[\kappa, \tau] && \text{Mapping from } \kappa \text{ to } \tau \\
\mid \quad & (\tau_1, \ldots, \tau_n) && \text{Tuple } (n \geq 1) \\
\mid \quad & \kw{struct}\ S && \text{User-defined struct} \\
\mid \quad & \kw{flag}\ F && \text{User-defined flag (enum)} \\
\mid \quad & \kw{event}\ E && \text{User-defined event} \\
\mid \quad & \kw{interface}\ I && \text{Interface type}
\end{align*}

\subsection{None Type}

The \kw{None} type represents computations that produce no useful value:
\[
\kw{None}
\]
This aligns with Python's \texttt{None}. The type $\kw{None}$ is used for:
\begin{itemize}
  \item Statements and expressions evaluated solely for side effects
  \item The return type of functions with no return value
  \item Terminating operations (\kw{raise}, \kw{selfdestruct}, \kw{break}, \kw{continue})
\end{itemize}
The type $\kw{None}$ cannot be used as a variable type, array element type,
or function parameter type.

\subsection{Type Classes}

We define the following type classes used throughout this document:

\begin{align*}
\mathit{IntegerT} &= \{\kw{int}N, \kw{uint}N \mid N \in \{8,16,\ldots,256\}\} \\
\mathit{NumericT} &= \mathit{IntegerT} \cup \{\kw{decimal}\} \\
\mathit{SignedT} &= \{\kw{int}N \mid N \in \{8,16,\ldots,256\}\} \cup \{\kw{decimal}\}
\end{align*}

%==============================================================================
\section{Typing Contexts and Judgments}
%==============================================================================

\subsection{Type Environment}

\[
\Gamma ::= \emptyset \mid \Gamma, x : \tau
\]

\subsection{Data Locations}

\[
\ell ::= \kw{storage} \mid \kw{transient} \mid \kw{memory} \mid \kw{calldata} \mid \kw{code}
\]

\subsection{Modifiability}

\[
\mu ::= \kw{constant} < \kw{runtime\_constant} < \kw{modifiable}
\]

For an expression $e$, we write $\mu(e)$ for its modifiability. Literals have $\mu = \kw{constant}$.
Compound expressions inherit modifiability from their subexpressions (e.g., operations on
constants yield constants). Constant folding reduces constant expressions to literals at compile time.

\subsection{State Mutability (for functions)}

\[
m ::= \kw{pure} < \kw{view} < \kw{nonpayable} < \kw{payable}
\]

\subsection{Judgment Forms}

We use the following judgment forms, following standard conventions~\cite{pierce2002types,dunfield2013complete}:

\begin{center}
\begin{tabular}{ll}
$\Gamma; m; \tau_r \vdash e : \tau$ & Expression $e$ has type $\tau$ \\
$\Gamma; m; \tau_r \vdash e : \tau \dashv \Gamma'$ & Expression $e$ has type $\tau$, extending context to $\Gamma'$ \\
$\subtype{\tau_1}{\tau_2}$ & Type $\tau_1$ is a subtype of $\tau_2$ \\
\end{tabular}
\end{center}

The notation threads:
\begin{itemize}
  \item $m$ --- the enclosing function's mutability
  \item $\tau_r$ --- the enclosing function's return type (used by \kw{return})
\end{itemize}

\paragraph{Unified Expression Typing.}
We use a single judgment form for both expressions and statements. Traditional ``statements''
and terminating operations (\kw{raise}, \kw{selfdestruct}) are expressions of type $\kw{None}$.

The type $\kw{None}$ cannot be used as a value: it cannot be assigned to variables
or passed as function arguments. This prevents constructs like \texttt{x = (y = 1)}
since assignment has type $\kw{None}$.

\paragraph{Output Context.}
Some expressions extend the typing context (e.g., variable declarations).
We write $\Gamma; m; \tau_r \vdash e : \tau \dashv \Gamma'$ when $e$ extends $\Gamma$ to $\Gamma'$.
When the context is unchanged, we omit $\dashv \Gamma'$.

%==============================================================================
\section{Subtyping Rules}
%==============================================================================

\fbox{$\subtype{\tau_1}{\tau_2}$} \quad ($\tau_1$ is a subtype of $\tau_2$)

\subsection{Structural Rules}

\begin{mathpar}
\inferrule*[right=S-Refl]
  { }
  {\subtype{\tau}{\tau}}

\inferrule*[right=S-Trans]
  {\subtype{\tau_1}{\tau_2} \\ \subtype{\tau_2}{\tau_3}}
  {\subtype{\tau_1}{\tau_3}}
\end{mathpar}

Note: Vyper has \emph{no implicit coercions} between numeric types. For example,
$\kw{uint8} \not<: \kw{uint256}$. All numeric types are only subtypes of themselves via \textsc{S-Refl}.

\subsection{Dynamic Array Subtyping}

Dynamic arrays are \emph{covariant} in element type and max length
(a smaller-capacity array can be assigned where a larger one is expected):

\begin{mathpar}
\inferrule*[right=S-DynArray]
  {\subtype{\tau_1}{\tau_2} \\ n_1 \leq n_2}
  {\subtype{\kw{DynArray}[\tau_1, n_1]}{\kw{DynArray}[\tau_2, n_2]}}
\end{mathpar}

Note: Static arrays $\tau[n]$ are \emph{invariant}---only \textsc{S-Refl} applies.

\subsection{Bytestring Subtyping}

Bytestrings with smaller max length are subtypes of those with larger max length:

\begin{mathpar}
\inferrule*[right=S-Bytes]
  {n_1 \leq n_2}
  {\subtype{\kw{Bytes}[n_1]}{\kw{Bytes}[n_2]}}

\inferrule*[right=S-String]
  {n_1 \leq n_2}
  {\subtype{\kw{String}[n_1]}{\kw{String}[n_2]}}
\end{mathpar}

\subsection{Nominal Types}

User-defined types use \emph{nominal} equality. We write $S_1 \equiv S_2$ to mean
that $S_1$ and $S_2$ are the \emph{same declaration} (object identity), not merely
structurally equivalent.

\begin{mathpar}
\inferrule*[right=S-Self]
  { }
  {\subtype{\kw{self}}{\kw{address}}}

\inferrule*[right=S-Struct]
  {S_1 \equiv S_2}
  {\subtype{\kw{struct}\ S_1}{\kw{struct}\ S_2}}

\inferrule*[right=S-Flag]
  {F_1 \equiv F_2}
  {\subtype{\kw{flag}\ F_1}{\kw{flag}\ F_2}}
\end{mathpar}

%==============================================================================
\section{Type Predicates}
%==============================================================================

The following predicates define validity conditions for type constructors.

\subsection{Valid Static Array Element Types}

The predicate $\validelem{\tau}$ determines if $\tau$ can be an element of a static array:

\begin{mathpar}
\inferrule*[right=VE-Prim]
  {\tau \in \{\kw{bool}, \kw{address}, \kw{decimal}\} \cup \mathit{IntegerT} \cup \{\kw{bytes}M\}}
  {\validelem{\tau}}

\inferrule*[right=VE-Struct]
  { }
  {\validelem{\kw{struct}\ S}}

\inferrule*[right=VE-DArray]
  { }
  {\validelem{\kw{DynArray}[\tau, n]}}

\inferrule*[right=VE-SArray]
  {\validelem{\tau}}
  {\validelem{\tau[n]}}

\inferrule*[right=VE-Interface]
  { }
  {\validelem{\kw{interface}\ I}}
\end{mathpar}

The following types are \textbf{not} valid static array elements:
$\kw{Bytes}[n]$, $\kw{String}[n]$, $\kw{flag}$, $\kw{HashMap}$, $\kw{event}$, tuple.

\subsection{Valid Dynamic Array Element Types}

The predicate $\validdarray{\tau}$ determines if $\tau$ can be an element of a dynamic array:

\begin{mathpar}
\inferrule*[right=VD-Elem]
  {\validelem{\tau}}
  {\validdarray{\tau}}

\inferrule*[right=VD-Bytes]
  { }
  {\validdarray{\kw{Bytes}[n]}}

\inferrule*[right=VD-String]
  { }
  {\validdarray{\kw{String}[n]}}

\inferrule*[right=VD-Flag]
  { }
  {\validdarray{\kw{flag}\ F}}
\end{mathpar}

The following types are \textbf{not} valid dynamic array elements:
$\kw{HashMap}$, $\kw{event}$, tuple.

\subsection{Valid HashMap Key Types}

The predicate $\validkey{\kappa}$ determines if $\kappa$ can be a HashMap key:

\begin{mathpar}
\inferrule*[right=VK-Prim]
  {\kappa \in \{\kw{bool}, \kw{address}, \kw{decimal}\} \cup \mathit{IntegerT} \cup \{\kw{bytes}M\}}
  {\validkey{\kappa}}

\inferrule*[right=VK-Bytes]
  { }
  {\validkey{\kw{Bytes}[n]}}

\inferrule*[right=VK-String]
  { }
  {\validkey{\kw{String}[n]}}

\inferrule*[right=VK-Flag]
  { }
  {\validkey{\kw{flag}\ F}}

\inferrule*[right=VK-Interface]
  { }
  {\validkey{\kw{interface}\ I}}
\end{mathpar}

The following types are \textbf{not} valid HashMap keys:
$\kw{struct}$, $\tau[n]$, $\kw{DynArray}$, $\kw{HashMap}$, $\kw{event}$, tuple.

%==============================================================================
\section{Expression Typing Rules}
%==============================================================================

\fbox{$\Gamma; m; \tau_r \vdash e : \tau$} \quad (expression $e$ has type $\tau$)

\medskip
\noindent
For brevity, we omit $\tau_r$ from rules that do not reference the return type.
The return type $\tau_r$ is only needed for \kw{return} expressions.

\subsection{Literals}

\begin{mathpar}
\inferrule*[right=T-True]
  { }
  {\Gamma; m \vdash \kw{True} : \kw{bool}}

\inferrule*[right=T-False]
  { }
  {\Gamma; m \vdash \kw{False} : \kw{bool}}

\inferrule*[right=T-IntLit]
  {-2^{N-1} \leq n \leq 2^{N-1} - 1}
  {\Gamma; m \vdash n : \kw{int}N}

\inferrule*[right=T-UintLit]
  {0 \leq n \leq 2^N - 1}
  {\Gamma; m \vdash n : \kw{uint}N}

\inferrule*[right=T-DecLit]
  {-2^{167}/10^{10} \leq d \leq (2^{167}-1)/10^{10}}
  {\Gamma; m \vdash d : \kw{decimal}}

\inferrule*[right=T-Addr]
  {\text{checksummed}(a)}
  {\Gamma; m \vdash \kw{0x}a : \kw{address}}

\inferrule*[right=T-BytesM]
  {|\mathit{hex}| = M \\ 1 \leq M \leq 32}
  {\Gamma; m \vdash \kw{0x}\mathit{hex} : \kw{bytes}M}

\inferrule*[right=T-BytesLit]
  {|s| \leq n}
  {\Gamma; m \vdash \kw{b"}s\kw{"} : \kw{Bytes}[n]}

\inferrule*[right=T-StrLit]
  {|s| \leq n}
  {\Gamma; m \vdash \kw{"}s\kw{"} : \kw{String}[n]}
\end{mathpar}

\subsection{Variables}

\begin{mathpar}
\inferrule*[right=T-Var]
  {(x : \tau) \in \Gamma}
  {\Gamma; m \vdash x : \tau}
\end{mathpar}

\subsection{State and Environment Variables}

\begin{mathpar}
\inferrule*[right=T-StateRead]
  {(x : \tau) \in \Gamma \\ \ell(x) \in \{\kw{storage}, \kw{transient}\} \\ m \neq \kw{pure}}
  {\Gamma; m \vdash x : \tau}

\inferrule*[right=T-MsgValue]
  {m = \kw{payable}}
  {\Gamma; m \vdash \kw{msg.value} : \kw{uint256}}
\end{mathpar}

Environment variables are accessible when $m \neq \kw{pure}$:

\begin{center}
\begin{tabular}{@{}llll@{}}
\toprule
\textbf{Variable} & \textbf{Type} & \textbf{Variable} & \textbf{Type} \\
\midrule
\kw{block.coinbase} & \kw{address} & \kw{msg.sender} & \kw{address} \\
\kw{block.number} & \kw{uint256} & \kw{msg.gas} / \kw{msg.mana} & \kw{uint256} \\
\kw{block.timestamp} & \kw{uint256} & \kw{msg.data} & \kw{Bytes} \\
\kw{block.difficulty} & \kw{uint256} & \kw{msg.value} & \kw{uint256} (payable only) \\
\kw{block.prevrandao} & \kw{bytes32} & \kw{tx.origin} & \kw{address} \\
\kw{block.gaslimit} & \kw{uint256} & \kw{tx.gasprice} & \kw{uint256} \\
\kw{block.basefee} & \kw{uint256} & \kw{chain.id} & \kw{uint256} \\
\kw{block.blobbasefee} & \kw{uint256} & & \\
\kw{block.prevhash} & \kw{bytes32} & & \\
\bottomrule
\end{tabular}
\end{center}

\subsection{Boolean Operations}

\begin{mathpar}
\inferrule*[right=T-And]
  {\Gamma; m \vdash e_1 : \kw{bool} \\ \Gamma; m \vdash e_2 : \kw{bool}}
  {\Gamma; m \vdash e_1\ \kw{and}\ e_2 : \kw{bool}}

\inferrule*[right=T-Or]
  {\Gamma; m \vdash e_1 : \kw{bool} \\ \Gamma; m \vdash e_2 : \kw{bool}}
  {\Gamma; m \vdash e_1\ \kw{or}\ e_2 : \kw{bool}}

\inferrule*[right=T-Not]
  {\Gamma; m \vdash e : \kw{bool}}
  {\Gamma; m \vdash \kw{not}\ e : \kw{bool}}
\end{mathpar}

\subsection{Arithmetic Operations}

\begin{mathpar}
\inferrule*[right=T-BinArith]
  {\Gamma; m \vdash e_1 : \tau \\ \Gamma; m \vdash e_2 : \tau \\ \tau \in \mathit{NumericT} \\
   \oplus \in \{+, -, *, /\!/, \%\}}
  {\Gamma; m \vdash e_1 \oplus e_2 : \tau}

\inferrule*[right=T-DecDiv]
  {\Gamma; m \vdash e_1 : \kw{decimal} \\ \Gamma; m \vdash e_2 : \kw{decimal}}
  {\Gamma; m \vdash e_1\ /\ e_2 : \kw{decimal}}

\inferrule*[right=T-Neg]
  {\Gamma; m \vdash e : \tau \\ \tau \in \mathit{SignedT}}
  {\Gamma; m \vdash -e : \tau}
\end{mathpar}

\subsection{Exponentiation}

Exponentiation requires at least one operand to be compile-time constant.
This enables static bounds checking:

\begin{mathpar}
\inferrule*[right=T-Pow]
  {\Gamma; m \vdash e_1 : \tau \\ \Gamma; m \vdash e_2 : \tau \\
   \tau \in \mathit{IntegerT} \\ \mu(e_1) = \kw{constant} \lor \mu(e_2) = \kw{constant}}
  {\Gamma; m \vdash e_1\ \kw{**}\ e_2 : \tau}
\end{mathpar}

For example, both \kw{x ** 2} and \kw{x ** (1 + 1)} are valid because \kw{2} and
\kw{1 + 1} (which folds to \kw{2}) are compile-time constants. However, \kw{x ** y}
where \kw{y} is a runtime variable is rejected. The rule ensures the compiler can
statically verify that the result does not overflow.

\subsection{Bitwise Operations}

\begin{mathpar}
\inferrule*[right=T-BitBin]
  {\Gamma; m \vdash e_1 : \tau \\ \Gamma; m \vdash e_2 : \tau \\
   \tau \in \mathit{IntegerT} \cup \{\kw{bytes}M, \kw{flag}\ F\} \\ \odot \in \{\&, |, \wedge\}}
  {\Gamma; m \vdash e_1\ \odot\ e_2 : \tau}

\inferrule*[right=T-BitNot]
  {\Gamma; m \vdash e : \tau \\ \tau \in \{\kw{uint256}, \kw{bytes32}, \kw{flag}\ F\}}
  {\Gamma; m \vdash \mathord{\sim} e : \tau}
\end{mathpar}

\subsection{Shift Operations}

Shifts are only allowed on 256-bit types:

\begin{mathpar}
\inferrule*[right=T-Shift]
  {\Gamma; m \vdash e_1 : \tau \\ \Gamma; m \vdash e_2 : \tau' \\ \tau' \in \mathit{IntegerT} \\
   \tau \in \{\kw{uint256}, \kw{int256}, \kw{bytes32}\} \\ \diamond \in \{\ll, \gg\}}
  {\Gamma; m \vdash e_1\ \diamond\ e_2 : \tau}
\end{mathpar}

\subsection{Comparisons}

\begin{mathpar}
\inferrule*[right=T-NumCmp]
  {\Gamma; m \vdash e_1 : \tau \\ \Gamma; m \vdash e_2 : \tau \\
   \tau \in \mathit{NumericT} \\ \bowtie\ \in \{<, \leq, >, \geq\}}
  {\Gamma; m \vdash e_1\ \bowtie\ e_2 : \kw{bool}}

\inferrule*[right=T-Eq]
  {\Gamma; m \vdash e_1 : \tau \\ \Gamma; m \vdash e_2 : \tau}
  {\Gamma; m \vdash e_1 == e_2 : \kw{bool}}

\inferrule*[right=T-NEq]
  {\Gamma; m \vdash e_1 : \tau \\ \Gamma; m \vdash e_2 : \tau}
  {\Gamma; m \vdash e_1\ !=\ e_2 : \kw{bool}}
\end{mathpar}

\subsection{Membership Tests}

\begin{mathpar}
\inferrule*[right=T-InSArray]
  {\Gamma; m \vdash e : \tau \\ \Gamma; m \vdash a : \tau[n]}
  {\Gamma; m \vdash e\ \kw{in}\ a : \kw{bool}}

\inferrule*[right=T-InDArray]
  {\Gamma; m \vdash e : \tau \\ \Gamma; m \vdash a : \kw{DynArray}[\tau, n]}
  {\Gamma; m \vdash e\ \kw{in}\ a : \kw{bool}}

\inferrule*[right=T-InFlag]
  {\Gamma; m \vdash e : \kw{flag}\ F \\ \Gamma; m \vdash f : \kw{flag}\ F}
  {\Gamma; m \vdash e\ \kw{in}\ f : \kw{bool}}
\end{mathpar}

\subsection{Subscript Access}

\begin{mathpar}
\inferrule*[right=T-SArrayIdx]
  {\Gamma; m \vdash e : \tau[n] \\ \Gamma; m \vdash i : \tau_i \\ \tau_i \in \mathit{IntegerT} \\
   \mu(i) = \kw{constant} \Rightarrow 0 \leq i < n}
  {\Gamma; m \vdash e[i] : \tau}

\inferrule*[right=T-DArrayIdx]
  {\Gamma; m \vdash e : \kw{DynArray}[\tau, n] \\ \Gamma; m \vdash i : \tau_i \\ \tau_i \in \mathit{IntegerT}}
  {\Gamma; m \vdash e[i] : \tau}

\inferrule*[right=T-MapIdx]
  {\Gamma; m \vdash h : \kw{HashMap}[\kappa, \tau] \\ \Gamma; m \vdash k : \kappa}
  {\Gamma; m \vdash h[k] : \tau}

\inferrule*[right=T-TupleIdx]
  {\Gamma; m \vdash t : (\tau_0, \ldots, \tau_{n-1}) \\ 0 \leq i < n \\ \mu(i) = \kw{constant}}
  {\Gamma; m \vdash t[i] : \tau_i}
\end{mathpar}

\subsection{Attribute Access}

\begin{mathpar}
\inferrule*[right=T-StructAttr]
  {\Gamma; m \vdash e : \kw{struct}\ S \\ (f : \tau) \in S}
  {\Gamma; m \vdash e.f : \tau}

\inferrule*[right=T-AddrAttr]
  {\Gamma; m \vdash e : \kw{address} \\ m \neq \kw{pure} \\
   (a, \tau_a) \in \{(\kw{balance}, \kw{uint256}), (\kw{codesize}, \kw{uint256}),
           (\kw{codehash}, \kw{bytes32}), (\kw{is\_contract}, \kw{bool})\}}
  {\Gamma; m \vdash e.a : \tau_a}
\end{mathpar}

\subsection{Composite Literals}

\begin{mathpar}
\inferrule*[right=T-ArrayLit]
  {\Gamma; m \vdash e_i : \tau \text{ for all } i \in 1..n}
  {\Gamma; m \vdash [e_1, \ldots, e_n] : \tau[n]}

\inferrule*[right=T-Tuple]
  {\Gamma; m \vdash e_i : \tau_i \text{ for all } i \in 1..n}
  {\Gamma; m \vdash (e_1, \ldots, e_n) : (\tau_1, \ldots, \tau_n)}
\end{mathpar}

\subsection{Struct Construction}

\begin{mathpar}
\inferrule*[right=T-StructCtor]
  {\kw{struct}\ S = \{f_1 : \tau_1, \ldots, f_n : \tau_n\} \\
   \Gamma; m \vdash e_i : \tau_i' \\ \subtype{\tau_i'}{\tau_i} \text{ for all } i}
  {\Gamma; m \vdash S(f_1 = e_1, \ldots, f_n = e_n) : \kw{struct}\ S}
\end{mathpar}

\subsection{Conditional Expression}

\begin{mathpar}
\inferrule*[right=T-IfExp]
  {\Gamma; m \vdash e_c : \kw{bool} \\ \Gamma; m \vdash e_1 : \tau \\ \Gamma; m \vdash e_2 : \tau}
  {\Gamma; m \vdash e_1\ \kw{if}\ e_c\ \kw{else}\ e_2 : \tau}
\end{mathpar}

\subsection{Type Conversion}

\begin{mathpar}
\inferrule*[right=T-Convert]
  {\Gamma; m \vdash e : \tau_1 \\ \convertible{\tau_1}{\tau_2}}
  {\Gamma; m \vdash \kw{convert}(e, \tau_2) : \tau_2}
\end{mathpar}

\subsection{Zero Initialization}

\begin{mathpar}
\inferrule*[right=T-Empty]
  { }
  {\Gamma; m \vdash \kw{empty}(\tau) : \tau}
\end{mathpar}

The \kw{empty} builtin returns the zero-initialized value for any type $\tau$.

\subsection{Dynamic Array Methods}

\begin{mathpar}
\inferrule*[right=T-Pop]
  {\Gamma; m \vdash a : \kw{DynArray}[\tau, n] \\ \mu(a) = \kw{modifiable}}
  {\Gamma; m \vdash a.\kw{pop}() : \tau}
\end{mathpar}

The \kw{pop} method can also be used as a statement (discarding the returned element);
see \textsc{T-PopStmt} in Section~\ref{sec:statements}.
The \kw{append} method is statement-only (it has no return value).

%==============================================================================
\section{Function Typing Rules}
%==============================================================================

\subsection{Function Types}

Function types include visibility and mutability:
\[
\sigma ::= (\tau_1, \ldots, \tau_n) \xrightarrow{v, m} \tau_r
\]
where $v \in \{\kw{internal}, \kw{external}, \kw{deploy}\}$ and $m \in \{\kw{pure}, \kw{view}, \kw{nonpayable}, \kw{payable}\}$.
Functions with no return annotation have return type $\kw{None}$.

\subsection{Function Definition}

\begin{mathpar}
\inferrule*[right=T-FunDef]
  {\Gamma, x_1 : \tau_1, \ldots, x_n : \tau_n; m_f; \tau_r \vdash \mathit{body} : \kw{None}}
  {\Gamma \vdash \kw{@}v\ \kw{@}m_f\ \kw{def}\ f(\overline{x : \tau}) \to \tau_r :
   (\overline{\tau}) \xrightarrow{v, m_f} \tau_r}
\end{mathpar}

The return type $\tau_r$ is bound in the body, allowing \textsc{T-Return} to verify
that returned expressions match the declared type.
Function parameters $x_i$ are added to the context with $\mu(x_i) = \kw{constant}$
(parameters are immutable and cannot be reassigned).

\subsection{Internal Function Call}

\begin{mathpar}
\inferrule*[right=T-InternalCall]
  {(f : (\overline{\tau}) \xrightarrow{\kw{internal}, m_f} \tau_f) \in \Gamma \\
   \Gamma; m \vdash e_i : \tau_i' \\ \subtype{\tau_i'}{\tau_i} \text{ for all } i \\
   m_f \leq m}
  {\Gamma; m \vdash f(\overline{e}) : \tau_f}
\end{mathpar}

When $\tau_f = \kw{None}$, the call produces $\kw{None}$ and can only be used as a statement.

\subsection{External Function Calls}

External calls require explicit \kw{extcall} or \kw{staticcall} keywords:

\begin{mathpar}
\inferrule*[right=T-ExtCall]
  {\Gamma; m \vdash e : \kw{interface}\ I \\
   (f : (\overline{\tau}) \xrightarrow{\kw{external}, m_f} \tau_f) \in I \\
   m_f \geq \kw{nonpayable} \\
   \Gamma; m \vdash e_i : \tau_i' \\ \subtype{\tau_i'}{\tau_i} \text{ for all } i \\
   m \geq \kw{nonpayable}}
  {\Gamma; m \vdash \kw{extcall}\ e.f(\overline{e}) : \tau_f}

\inferrule*[right=T-StaticCall]
  {\Gamma; m \vdash e : \kw{interface}\ I \\
   (f : (\overline{\tau}) \xrightarrow{\kw{external}, m_f} \tau_f) \in I \\
   m_f \in \{\kw{view}, \kw{pure}\} \\ m_f \leq m \\
   \Gamma; m \vdash e_i : \tau_i' \\ \subtype{\tau_i'}{\tau_i} \text{ for all } i}
  {\Gamma; m \vdash \kw{staticcall}\ e.f(\overline{e}) : \tau_f}
\end{mathpar}

When $\tau_f = \kw{None}$, the call produces $\kw{None}$.

%==============================================================================
\section{None-Typed Expressions (Statements)}
\label{sec:statements}
%==============================================================================

\fbox{$\Gamma; m; \tau_r \vdash e : \kw{None}$} \quad (expression $e$ has type $\kw{None}$)

\medskip
\noindent
Expressions of type $\kw{None}$ are traditionally called ``statements.''
They are evaluated for side effects and produce no useful value.

\subsection{Method Calls}

\begin{mathpar}
\inferrule*[right=T-Append]
  {\Gamma; m \vdash a : \kw{DynArray}[\tau, n] \\ \Gamma; m \vdash e : \tau' \\ \subtype{\tau'}{\tau} \\
   \mu(a) = \kw{modifiable}}
  {\Gamma; m \vdash a.\kw{append}(e) : \kw{None}}

\inferrule*[right=T-PopStmt]
  {\Gamma; m \vdash a : \kw{DynArray}[\tau, n] \\ \mu(a) = \kw{modifiable}}
  {\Gamma; m \vdash a.\kw{pop}() : \kw{None}}
\end{mathpar}

The \kw{pop} method can be used both as an expression (returning $\tau$; see \textsc{T-Pop})
or as a statement (discarding the result; \textsc{T-PopStmt}). Since $\tau \neq \kw{None}$
for valid dynamic array element types, both rules are needed.

\subsection{Variable Declaration}

\begin{mathpar}
\inferrule*[right=T-VarDecl]
  {\Gamma; m \vdash e : \tau' \\ \subtype{\tau'}{\tau} \\ \tau' \neq \kw{None}}
  {\Gamma; m \vdash (x : \tau = e) : \kw{None} \dashv \Gamma, x : \tau}
\end{mathpar}

The premise $\tau' \neq \kw{None}$ ensures that $\kw{None}$-typed expressions cannot be assigned.

\subsection{Assignment}

\begin{mathpar}
\inferrule*[right=T-Assign]
  {(x : \tau) \in \Gamma \\ \Gamma; m \vdash e : \tau' \\
   \subtype{\tau'}{\tau} \\ \tau' \neq \kw{None} \\ \mu(x) = \kw{modifiable} \\
   \ell(x) \in \{\kw{storage}, \kw{transient}\} \Rightarrow m \geq \kw{nonpayable}}
  {\Gamma; m \vdash x = e : \kw{None}}

\inferrule*[right=T-AugAssign]
  {(x : \tau) \in \Gamma \\ \Gamma; m \vdash e : \tau \\ \tau \in \mathit{NumericT} \\
   \oplus \in \{+, -, *, /\!/, \%, \kw{**}\} \\
   \mu(x) = \kw{modifiable} \\
   \ell(x) \in \{\kw{storage}, \kw{transient}\} \Rightarrow m \geq \kw{nonpayable}}
  {\Gamma; m \vdash x\ \oplus\!\!= \ e : \kw{None}}

\inferrule*[right=T-AugAssignBit]
  {(x : \tau) \in \Gamma \\ \Gamma; m \vdash e : \tau \\
   \tau \in \mathit{IntegerT} \cup \{\kw{bytes}M, \kw{flag}\ F\} \\
   \odot \in \{\&, |, \wedge\} \\
   \mu(x) = \kw{modifiable} \\
   \ell(x) \in \{\kw{storage}, \kw{transient}\} \Rightarrow m \geq \kw{nonpayable}}
  {\Gamma; m \vdash x\ \odot\!\!= \ e : \kw{None}}

\inferrule*[right=T-AugAssignShift]
  {(x : \tau) \in \Gamma \\ \Gamma; m \vdash e : \tau' \\ \tau' \in \mathit{IntegerT} \\
   \tau \in \{\kw{uint256}, \kw{int256}, \kw{bytes32}\} \\ \diamond \in \{\ll, \gg\} \\
   \mu(x) = \kw{modifiable} \\
   \ell(x) \in \{\kw{storage}, \kw{transient}\} \Rightarrow m \geq \kw{nonpayable}}
  {\Gamma; m \vdash x\ \diamond\!\!= \ e : \kw{None}}
\end{mathpar}

\subsection{Control Flow}

\begin{mathpar}
\inferrule*[right=T-If]
  {\Gamma; m \vdash e : \kw{bool} \\
   \Gamma; m; \tau_r \vdash s_1 : \kw{None} \\
   \Gamma; m; \tau_r \vdash s_2 : \kw{None}}
  {\Gamma; m; \tau_r \vdash \kw{if}\ e\kw{:}\ s_1\ \kw{else:}\ s_2 : \kw{None}}

\inferrule*[right=T-ForRange]
  {\Gamma; m \vdash e_1 : \tau \\ \Gamma; m \vdash e_2 : \tau \\ \tau \in \mathit{IntegerT} \\
   \Gamma, i : \tau; m; \tau_r \vdash s : \kw{None}}
  {\Gamma; m; \tau_r \vdash \kw{for}\ i : \tau\ \kw{in range}(e_1, e_2)\kw{:}\ s : \kw{None}}

\inferrule*[right=T-ForSArray]
  {\Gamma; m \vdash a : \tau[n] \\
   \Gamma, x : \tau; m; \tau_r \vdash s : \kw{None}}
  {\Gamma; m; \tau_r \vdash \kw{for}\ x : \tau\ \kw{in}\ a\kw{:}\ s : \kw{None}}

\inferrule*[right=T-ForDArray]
  {\Gamma; m \vdash a : \kw{DynArray}[\tau, n] \\
   \Gamma, x : \tau; m; \tau_r \vdash s : \kw{None}}
  {\Gamma; m; \tau_r \vdash \kw{for}\ x : \tau\ \kw{in}\ a\kw{:}\ s : \kw{None}}
\end{mathpar}

\subsection{Return}

\begin{mathpar}
\inferrule*[right=T-Return]
  {\Gamma; m \vdash e : \tau' \\ \subtype{\tau'}{\tau_r} \\ \tau' \neq \kw{None}}
  {\Gamma; m; \tau_r \vdash \kw{return}\ e : \kw{None}}

\inferrule*[right=T-ReturnVoid]
  {\tau_r = \kw{None}}
  {\Gamma; m; \tau_r \vdash \kw{return} : \kw{None}}
\end{mathpar}

Note: A function with no return value has $\tau_r = \kw{None}$. The premise $\tau' \neq \kw{None}$
in \textsc{T-Return} prevents returning $\kw{None}$-typed expressions.

\subsection{Assert}

Assert can optionally take a revert message:

\begin{mathpar}
\inferrule*[right=T-Assert]
  {\Gamma; m \vdash e : \kw{bool}}
  {\Gamma; m \vdash \kw{assert}\ e : \kw{None}}

\inferrule*[right=T-AssertMsg]
  {\Gamma; m \vdash e : \kw{bool} \\ \Gamma; m \vdash \mathit{msg} : \kw{String}[n] \\ n \leq 1024}
  {\Gamma; m \vdash \kw{assert}\ e,\ \mathit{msg} : \kw{None}}

\inferrule*[right=T-AssertUnreach]
  {\Gamma; m \vdash e : \kw{bool}}
  {\Gamma; m \vdash \kw{assert}\ e,\ \kw{UNREACHABLE} : \kw{None}}
\end{mathpar}

\subsection{Terminating Expressions}

Expressions that never return normally have type $\kw{None}$.
Code after these expressions is unreachable.

\begin{mathpar}
\inferrule*[right=T-Raise]
  {\Gamma; m \vdash e : \kw{String}[n] \\ n \leq 1024}
  {\Gamma; m \vdash \kw{raise}\ e : \kw{None}}

\inferrule*[right=T-RaiseUnreach]
  { }
  {\Gamma; m \vdash \kw{raise}\ \kw{UNREACHABLE} : \kw{None}}

\inferrule*[right=T-Selfdestruct]
  {\Gamma; m \vdash e : \kw{address} \\ m \geq \kw{nonpayable}}
  {\Gamma; m \vdash \kw{selfdestruct}(e) : \kw{None}}

\inferrule*[right=T-Break]
  {\text{inside a loop}}
  {\Gamma; m \vdash \kw{break} : \kw{None}}

\inferrule*[right=T-Continue]
  {\text{inside a loop}}
  {\Gamma; m \vdash \kw{continue} : \kw{None}}
\end{mathpar}

The \kw{break} and \kw{continue} statements transfer control out of the current block,
making subsequent code unreachable.

\subsection{Event Logging}

\begin{mathpar}
\inferrule*[right=T-Log]
  {\kw{event}\ E = \{a_1 : \tau_1, \ldots, a_n : \tau_n\} \\
   \Gamma; m \vdash e_i : \tau_i' \\ \subtype{\tau_i'}{\tau_i} \text{ for all } i \\
   m \geq \kw{nonpayable}}
  {\Gamma; m \vdash \kw{log}\ E(a_1 = e_1, \ldots, a_n = e_n) : \kw{None}}
\end{mathpar}

\subsection{Ether Transfer and Low-Level Calls}

\begin{mathpar}
\inferrule*[right=T-Send]
  {\Gamma; m \vdash e_1 : \kw{address} \\ \Gamma; m \vdash e_2 : \kw{uint256} \\
   m \geq \kw{nonpayable}}
  {\Gamma; m \vdash \kw{send}(e_1, e_2) : \kw{None}}

\inferrule*[right=T-RawCallStmt]
  {\Gamma; m \vdash e_1 : \kw{address} \\ \Gamma; m \vdash e_2 : \kw{Bytes}[n] \\
   \text{no \kw{max\_outsize} specified} \\ m \geq \kw{nonpayable}}
  {\Gamma; m \vdash \kw{raw\_call}(e_1, e_2, \ldots) : \kw{None}}
\end{mathpar}

The \kw{send} builtin accepts an optional \kw{gas} keyword argument of type \kw{uint256}.

\begin{mathpar}
\inferrule*[right=T-RawCallExpr]
  {\Gamma; m \vdash e_1 : \kw{address} \\ \Gamma; m \vdash e_2 : \kw{Bytes}[n] \\
   \kw{max\_outsize} = k \\ m \geq \kw{nonpayable}}
  {\Gamma; m \vdash \kw{raw\_call}(e_1, e_2, \ldots, \kw{max\_outsize}=k) : \kw{Bytes}[k]}
\end{mathpar}

When \kw{max\_outsize} is specified, \kw{raw\_call} returns \kw{Bytes}[$k$].

\section{Type Conversion Rules}
%==============================================================================

The predicate $\convertible{\tau_1}{\tau_2}$ defines valid explicit conversions:

\subsection{Integer Conversions}

\begin{mathpar}
\inferrule*[right=Conv-IntInt]
  {\tau_1 \in \mathit{IntegerT} \\ \tau_2 \in \mathit{IntegerT}}
  {\convertible{\tau_1}{\tau_2}}

\inferrule*[right=Conv-IntDec]
  {\tau \in \mathit{IntegerT}}
  {\convertible{\tau}{\kw{decimal}}}

\inferrule*[right=Conv-DecInt]
  {\tau \in \mathit{IntegerT}}
  {\convertible{\kw{decimal}}{\tau}}

\inferrule*[right=Conv-BoolInt]
  {\tau \in \mathit{IntegerT}}
  {\convertible{\kw{bool}}{\tau}}

\inferrule*[right=Conv-BoolDec]
  { }
  {\convertible{\kw{bool}}{\kw{decimal}}}
\end{mathpar}

\subsection{Byte Conversions}

\begin{mathpar}
\inferrule*[right=Conv-BytesMInt]
  { }
  {\convertible{\kw{bytes}M}{\kw{int}N} \land \convertible{\kw{bytes}M}{\kw{uint}N}}

\inferrule*[right=Conv-IntBytesM]
  { }
  {\convertible{\kw{int}N}{\kw{bytes}M} \land \convertible{\kw{uint}N}{\kw{bytes}M}}

\inferrule*[right=Conv-BytesNInt]
  {\tau \in \mathit{IntegerT}}
  {\convertible{\kw{Bytes}[n]}{\tau}}

\inferrule*[right=Conv-BytesNDec]
  { }
  {\convertible{\kw{Bytes}[n]}{\kw{decimal}}}
\end{mathpar}

\subsection{Address Conversions}

\begin{mathpar}
\inferrule*[right=Conv-AddrInt]
  { }
  {\convertible{\kw{address}}{\kw{uint160}} \land \convertible{\kw{uint160}}{\kw{address}}}

\inferrule*[right=Conv-AddrBytes]
  { }
  {\convertible{\kw{address}}{\kw{bytes20}} \land \convertible{\kw{bytes20}}{\kw{address}}}
\end{mathpar}

\subsection{Boolean Conversions}

\begin{mathpar}
\inferrule*[right=Conv-ToBool]
  {\tau \in \mathit{IntegerT} \cup \{\kw{decimal}, \kw{bytes}M, \kw{address}, \kw{Bytes}[n], \kw{String}[n]\}}
  {\convertible{\tau}{\kw{bool}}}
\end{mathpar}

\subsection{Flag Conversions}

\begin{mathpar}
\inferrule*[right=Conv-Flag]
  { }
  {\convertible{\kw{flag}\ F}{\kw{uint256}} \land \convertible{\kw{uint256}}{\kw{flag}\ F}}
\end{mathpar}

\section{Location Constraints}
%==============================================================================

\begin{mathpar}
\inferrule*[right=L-HashMap]
  {\ell \in \{\kw{storage}, \kw{transient}\}}
  {\kw{HashMap}[\kappa, \tau]\ \text{valid at}\ \ell}

\inferrule*[right=L-ExtParam]
  {f\ \text{is external}}
  {\text{params}(f)\ \text{have location}\ \kw{calldata}}

\inferrule*[right=L-IntParam]
  {f\ \text{is internal}}
  {\text{params}(f)\ \text{have location}\ \kw{memory}}

\inferrule*[right=L-Immutable]
  {\ell(x) = \kw{code} \\ f\ \text{is not constructor}}
  {\mu(x) = \kw{runtime\_constant}}
\end{mathpar}

\section{Summary}
%==============================================================================

The Vyper type system is characterized by:

\begin{enumerate}
  \item \textbf{Unified expression typing}: Statements and terminating operations
        are expressions of type $\kw{None}$
  \item \textbf{No implicit coercions}: Types must match exactly or through explicit subtyping
  \item \textbf{Nominal typing}: User-defined types use identity comparison ($\equiv$)
  \item \textbf{Structural subtyping}: Bytestrings and dynamic arrays by max length
  \item \textbf{Effect tracking}: Function mutability ($m$) threads through all judgments
  \item \textbf{Location tracking}: Variables have associated storage locations
  \item \textbf{Explicit conversions}: Via \kw{convert()} with bounds checking
  \item \textbf{Static bounds}: Integer overflow checked at compile-time where possible
  \item \textbf{Value restriction}: $\kw{None}$ cannot be assigned or passed as arguments
\end{enumerate}
